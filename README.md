# Nova AI Assistant Android

Nova is a Hindi, Hinglish, and English voice-enabled AI assistant for Android.

## Vision

Nova is designed to communicate in a natural and friendly way. It can understand user questions, explain mistakes politely, respond with empathy when the user feels sad, and ask for confirmation before sensitive actions.

## Planned Features

- Hindi, Hinglish, and English chat
- Voice input
- Text-to-speech replies
- Natural and friendly conversation
- Polite correction of mistakes
- Emotional support and empathetic responses
- Notes and task management
- Reminders and alarms
- Dark futuristic user interface
- Local storage for notes and tasks
- AI API integration
- Safe approval system for sensitive actions

## Safety Principles

- Nova will not pretend to be a real human.
- Nova will clearly say when it is an AI assistant.
- Nova will not give dangerous or harmful instructions.
- Nova will ask for confirmation before sending messages, deleting data, making calls, or changing settings.
- API keys and private information must never be published in the repository.

## Technology

- Kotlin
- Jetpack Compose
- Android SpeechRecognizer
- Android TextToSpeech
- Room Database
- WorkManager and AlarmManager
- Secure AI API integration

## Project Status

The project is currently in the planning and initial development phase.

## Development Rule

Every feature should include:

1. A clear explanation.
2. The file name and exact location.
3. Complete copy-paste-ready code.
4. Required permissions or dependencies.
5. Instructions to test the feature.
6. Common errors and their solutions.

## Example Conversation

User: Nova, mujhse galti ho gayi.

Nova: Koi baat nahi. Galti se seekhna normal hai. Agar tum chaho, hum milkar samajh sakte hain ki kya hua aur agali baar ise kaise avoid karna hai.

User: Nova, main udaas hoon.

Nova: Mujhe afsos hai ki tum aisa mehsoos kar rahe ho. Main tumhari baat sun sakti hoon. Kya tum batana chahoge ki kya hua?
